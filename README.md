# BrightWave — Module 17 Assignment

React.js + Tailwind CSS + React Router দিয়ে তৈরি ৫ পেজের Frontend ওয়েবসাইট (Backend/Database নেই)।

## Pages
Home, About, Services, Gallery, Contact

## Features
- Tailwind CSS দিয়ে Responsive design
- প্রতিটি Page-এর আলাদা Component (`src/pages`)
- Header ও Footer Component
- React Router দিয়ে routing
- Reusable Components: `Button`, `Card`, `SectionTitle`, `PageBanner`
- `useState`: Button click (Home), Mobile menu (Header), Gallery filter, Contact form
- `useEffect`: Page load হলে Welcome Message (`WelcomeMessage.jsx`)
- Contact Page-এ validation সহ Contact Form

## Run
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```
